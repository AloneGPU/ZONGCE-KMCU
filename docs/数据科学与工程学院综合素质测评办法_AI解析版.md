# 1. 文件基本信息

-   适用对象：数据科学与工程学院普通全日制学生。
-   测评周期：以一学年为周期，每年9月组织测评。
-   评分方式：定性评价 + 定量评分，最终采用百分制。
-   核心目标：
    -   学生全面发展评价；
    -   评优评奖依据；
    -   就业推荐参考；
    -   毕业综合评价依据。

原文件明确指出，综合测评指标体系包含六个维度：德育、智育、体育、能力、美育、劳动，权重分别为0.2、0.4、0.1、0.1、0.1、0.1。fileciteturn0file0L43-L46

# 2. 综合测评总分计算公式

## 总公式

    综合测评总分 =
    德育素质分 × 0.2
    + 智育素质分 × 0.4
    + 体育素质分 × 0.1
    + 能力素质分 × 0.1
    + 美育素质分 × 0.1
    + 劳动素质分 × 0.1

综合测评成绩采用百分制。fileciteturn0file0L75-L76

# 3. 六大素质评分体系

  模块         权重            满分基础
  ---------- ------ -------------------
  德育素质      20%     基础60分±加减分
  智育素质      40%            学业成绩
  体育素质      10%   体育基础+体育能力
  能力素质      10%   基础60分+能力加分
  美育素质      10%   基础60分+美育加分
  劳动素质      10%   基础60分+劳动加分

# 4. 德育素质评分

## 4.1 评价内容

包括：

-   政治表现
-   遵纪守法
-   社会公德
-   个人品质
-   人际关系

------------------------------------------------------------------------

## 4.2 德育加分

同一事项获得多个荣誉，只取最高等级。

  荣誉级别             加分
  ------------------ ------
  国家级及以上         30分
  省（厅）级           20分
  市（县）级           15分
  学校/街道/社区级     10分
  学院级                5分

其他：

-   献血：+2分（全年一次，不累计次数）。

------------------------------------------------------------------------

## 4.3 德育扣分

  情况                                    扣分
  ---------------------------------- ---------
  严重违法违纪、造成恶劣影响           德育0分
  记过及以上处分                         -40分
  警告、严重警告处分                     -30分
  校级通报批评                           -20分
  院级处分                               -10分
  宿舍卫生不合格、晚归、违章电器等     -5分/次
  不参加班团活动                       -2分/次

扣分可累计，最终低于0分按0分计算。

------------------------------------------------------------------------

## 4.4 德育折算

    德育素质分 =
    (60 + 德育加分 - 德育扣分) × 0.2

德育低于60分，当年不能参加奖项评定。

------------------------------------------------------------------------

# 5. 智育素质评分

## 5.1 计算方式

智育成绩来源：

-   教务系统学生个人考评学年课程成绩；
-   按平均学分绩（加权平均分）计算。

公式：

    智育素质分 = 学业成绩 × 0.4

智育低于60分，当年不能参加奖项评定。

------------------------------------------------------------------------

  分数     等级
  -------- --------
  90-100   优秀
  80-89    良好

    毕业综合评价 =
    所有学年综合测评总分平均值

# 17. AI计算规则总结

AI计算学生综测时：

1.  获取六项基础分；
2.  按权重计算；
3.  处理所有加分；
4.  处理所有扣分；
5.  检查是否存在取消评奖条件；
6.  输出：
    -   六项分数；
    -   权重贡献；
    -   总分；
    -   等级；
    -   可优化方向。

核心公式：

    Final =
    德育×0.2
    +智育×0.4
    +体育×0.1
    +能力×0.1
    +美育×0.1
    +劳动×0.1
